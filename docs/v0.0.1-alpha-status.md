## Executive Summary

tollgate-module-basic-rust is a Rust rewrite of tollgate-module-basic-go,
designed as a drop-in replacement that uses CDK (Cashu Dev Kit) instead of
gonuts for the wallet layer. This alpha demonstrates compilation for all
OpenWrt MIPS targets, correct HTTP behavior, and automatic wallet migration
from the Go binary.

**NOT production-ready.** Physical router testing, full feature parity,
and operator tooling are still required before production deployment.

## Wallet Migration (Go → Rust)

Automatic on first boot when replacing the Go binary:

```
1. Detect gonuts wallet.db (bbolt)
2. Run gonuts-export → tokens.jsonl
3. For each token: wallet.receive(token)
4. Write .migration_complete marker
5. Rename wallet.db → wallet.db.pre-migration
```

**Verified on GCP:** Go TollGate creates wallet.db → Rust TollGate detects it,
attempts migration, creates new CDK wallet, serves HTTP with preserved config.

## Known Limitations

1. **Not deployed on physical hardware** — all testing done in QEMU/GCP
2. **gonuts-export binary required** for auto-migration (must be installed alongside)
3. **CDK fork dependency** — Amperstrand/cdk needed until upstream merges
4. **No integration tests against live mints** — unit tests only
5. **Wireless orchestration incomplete** — scanner/connector work but full event loop not wired in main.rs
6. **CLI socket needs /var/run/ permissions** — works as root, not as unprivileged user
